## Shared engineering workflow

- Use `maintain-project-authorities` to create, semantically update, verify, or compact structured project authorities.
- Apply `review-and-remediate` after implementation and initial validation, with review proportional to the change, before the final report or any authorized commit.
- Load the skills' relevant references progressively, then only the project authorities and evidence needed for the task.
- Keep project decisions, contracts, architecture, roadmap, and other project authorities in their repositories; shared skills provide procedures and documentary guidance.
